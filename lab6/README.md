# Lab 6 – Code Coverage and Branch Coverage Testing

## Objective
To perform code coverage and branch coverage testing on the Spam Scoring application using Python testing tools.

## Project Description
This lab focuses on evaluating the effectiveness of test cases by measuring how much of the application code is executed and whether all possible decision branches are tested.

## Tools and Technologies Used
- **Python** – Programming language used for the application and test cases.
- **pytest** – Testing framework used to execute test cases.
- **Coverage.py** – Used to measure code coverage.
- **Branch Coverage** – Used to verify that both outcomes of conditional statements are tested.
